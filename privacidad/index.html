Política de privacidad

Última actualización: octubre de 2026

Este sitio (gayovaldez.com) es la página oficial del artista Gayo Valdez. No pedimos cuentas, no usamos cookies de rastreo y no vendemos datos.

Qué datos usamos

El sitio no recopila datos personales. Si escribes por correo, tu mensaje se usa solo para responderte.

Apps de Gayo Valdez

Las herramientas con las que Gayo Valdez administra su propio contenido se conectan, con su autorización, a sus cuentas de YouTube, TikTok, Instagram y Spotify, solo para publicar contenido y consultar estadísticas de esas mismas cuentas. No acceden, guardan ni comparten datos de otras personas.

El uso y la transferencia de información recibida de las API de Google cumplen con la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Conservación y eliminación

Los tokens de acceso se guardan de forma segura y se eliminan al desconectar la cuenta. Puedes pedir la eliminación de cualquier dato escribiendo al correo de contacto.

Retirar el acceso

Puedes revocar el acceso en cualquier momento desde la configuración de seguridad de cada plataforma.
